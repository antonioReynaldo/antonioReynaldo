## 💼 Proyectos Destacados

### 🏆 To-Do List Application (Full Stack)

**[Código Backend](https://github.com/antonioReynaldo/to-do-backend)**
**[Código Fronted](https://github.com/antonioReynaldo/to-do-frontend)**


Aplicación completa de gestión de tareas con arquitectura robusta, autenticación JWT y persistencia en base de datos PostgreSQL.

**Tecnologías:** React 19, TypeScript, Tailwind CSS, Node.js, Express, PostgreSQL, JWT, React Hook Form, Zod

**Características Avanzadas:**

- ✅ **Autenticación JWT completa** - Registro, login, refresh tokens, logout
- ✅ **CRUD completo de tareas** - Con estados: pendiente, en proceso, finalizada
- ✅ **Sistema de subtareas** - Jerarquía y organización avanzada
- ✅ **Categorías personalizadas** - Clasificación por etiquetas
- ✅ **Modo claro/oscuro** - Interfaz adaptable a preferencias
- ✅ **Actualizaciones en tiempo real** - Sin recargas de página
- ✅ **Validación robusta** - Zod en frontend y backend
- ✅ **Formularios avanzados** - React Hook Form con validación
- ✅ **Rutas protegidas** - Middleware de autenticación
- ✅ **API RESTful completa** - 20+ endpoints documentados
- ✅ **Diseño responsive** - Mobile-first con Tailwind CSS

**Estructura del Proyecto:**

```
todo-list-fullstack/
├── backend-todo-list/
│   ├── src/
│   │   ├── controllers/     # Lógica de las rutas
│   │   ├── services/        # Lógica de negocio
│   │   ├── models/          # Modelos de datos
│   │   ├── routes/          # Definición de endpoints
│   │   ├── middlewares/     # Auth, validation, logging
│   │   ├── validators/      # Esquemas con Zod
│   │   └── database/        # Conexión a PostgreSQL
│   └── package.json
└── frontend-todo-list/
    ├── src/
    │   ├── components/      # Componentes reutilizables
    │   ├── pages/           # Páginas principales
    │   │   ├── LoginPage
    │   │   ├── RegisterPage
    │   │   └── DashboardPage
    │   ├── routes/          # Enrutamiento con React Router
    │   ├── services/        # API services con Axios
    │   ├── context/         # Contextos globales
    │   ├── hooks/           # Custom hooks
    │   └── schemas/         # Validación con Zod
    └── package.json
```

**API Endpoints:**

| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/auth/register` | POST | Registrarse |
| `/api/auth/login` | POST | Iniciar sesión |
| `/api/auth/refresh` | POST | Renovar token |
| `/api/auth/logout` | POST | Cerrar sesión |
| `/api/users/profile` | PUT | Actualizar perfil |
| `/api/users/password` | PUT | Cambiar contraseña |
| `/api/tasks` | GET | Obtener todas las tareas |
| `/api/tasks/:id` | GET | Obtener tarea específica |
| `/api/tasks` | POST | Crear tarea |
| `/api/tasks/:id` | PUT | Editar tarea |
| `/api/tasks/:id` | DELETE | Eliminar tarea |
| `/api/tasks/:id/start` | PATCH | Empezar tarea |
| `/api/tasks/:id/complete` | PATCH | Finalizar tarea |
| `/api/tasks/reorder` | PATCH | Reordenar tareas |
| `/api/subtasks/:id` | POST | Crear subtarea |
| `/api/subtasks/:id` | PATCH | Editar/completar subtarea |
| `/api/categories/` | GET | Obtener categorías |
